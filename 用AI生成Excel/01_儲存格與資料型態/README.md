## 1️⃣ 白話需求（學生會怎麼跟 AI 說）

> 「我是攝影社總務，要記錄社團每一筆收入和支出，期末給老師查帳。要有日期、收入還是支出、做什麼用、多少錢、誰經手、收據編號。收據編號是 0001 這種四碼的。」

把這段話套進 [通用提示詞](../通用提示詞.md) 的第 ① 段，AI 就會交出本課的規範書。

## 2️⃣ 本課觀念在規範書哪裡

| 規範書位置 | 寫了什麼 | 為什麼重要 |
| :--- | :--- | :--- |
| **C2・A 欄 日期** | 資料型態「日期」、格式 `yyyy-mm-dd` | 存成真日期才能排序、取月份 |
| **C2・D 欄 金額** | 資料型態「數值」、格式 `#,##0`、不可輸入「元」 | 數值才能加總 |
| **C2・F 欄 收據編號** | 資料型態「文字」 | 存成數值會變成 `1`，前導 0 不見 |
| **C1 第 3 條** | 收入／支出另開一欄 | 一格只放一件事，不寫成「+7500」「-1600」 |
| **C6 對齊** | 不手動改對齊 | 讓你能從「靠左／靠右」判斷型態 |

## 3️⃣ 打開 xlsx 觀察（只看，不用改）

### 工作表「收支紀錄」
- [ ] 點 **A2**：儲存格顯示 `2026-02-23`。它**靠右**，表示是日期不是文字。
- [ ] 點 **D2**：顯示 `7,500`，資料編輯列卻是 `7500`。千分位逗號只是**顯示格式**。
- [ ] 點 **F2**：顯示 `0001`，而且**靠左**。這是文字，所以 0 保留下來。
- [ ] 往下捲動：第 1 列表頭固定不動，這是**凍結窗格**。

### 工作表「型態對照」
- [ ] 看 **B2～B4**（文字）和 **C2～C4**（數值）：一個靠左、一個靠右。
- [ ] 看第 5 列加總：**B5 = 0**、**C5 = 7,000**。文字不會被加總。
- [ ] 看第 7 列取月份：**B7 = `#VALUE!`**、**C7 = 3**。文字日期無法計算。
- [ ] 看第 8 列：數值 `12` 和文字 `0012` 的差別。

> 💡 如果你的 Excel 在 B2 左上角顯示綠色小三角形，那是 Excel 在提醒你：「這個數字被存成文字了」。

## 4️⃣ AI 常見出錯點：在規範書階段就抓出來

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 日期存成文字 | C2 日期欄資料型態寫「文字」或沒寫 | 「日期，格式 yyyy-mm-dd」 |
| 金額帶單位 | 示範資料出現 `7,500元` | 「數值，格式 #,##0，不含單位」 |
| 收支用正負號 | 金額欄出現 `-1600` | 「另開收支類別欄，金額一律正數」 |
| 編號變數值 | 收據編號資料型態寫「數值」 | 「文字，保留前導 0」 |
