## 1️⃣ 白話需求

> 「訂單只想打產品編號和數量，產品名稱跟價格自己跑出來。價格調整時只改一個地方。編號打錯要看得出來，不要默默算成 0。」

## 2️⃣ 為什麼要拆主檔？

| 每張訂單都手打名稱與單價 | 訂單只打編號，名稱單價查主檔 |
| :--- | :--- |
| 「27吋螢幕」「27 吋螢幕」「27寸螢幕」三種寫法 | 名稱只在主檔寫一次 |
| 漲價時要改幾百筆訂單 | 改主檔一格，所有訂單自動更新 |
| 打錯價格看不出來 | 價格都來自主檔 |

## 3️⃣ XLOOKUP 怎麼讀

```
=XLOOKUP( C2 , T_Product[產品編號] , T_Product[產品名稱] , "查無此編號" )
          ①         ②                    ③                    ④
① 要找什麼：這筆訂單的產品編號
② 去哪裡找：主檔的「產品編號」欄
③ 找到後回傳什麼：同一列的「產品名稱」
④ 找不到時顯示什麼
```

> 💡 你可能聽過 VLOOKUP。XLOOKUP 是新版的替代品：不用數「第幾欄」，主檔增刪欄位也不會壞掉。

## 5️⃣ 打開 xlsx 觀察

- [ ] 點訂單明細 **E2**：`=XLOOKUP(C2,T_Product[產品編號],T_Product[產品名稱],"查無此編號")`。
- [ ] 對照：O-0001 的 `P-003`，到「產品主檔」找到 27 吋螢幕、6,990，和 E2、G2 一致。
- [ ] 看第 7 列 **O-0006**：`P-999` 查不到，整列紅底，產品名稱「查無此編號」，小計 0。
- [ ] 切到「訂單彙總」：營收總計 **112,710**、查無編號筆數 **1**。
- [ ] 想一想：如果 G 欄找不到時也顯示文字，H 欄的 `=D7*G7` 會變成什麼？（答案：`#VALUE!`）

> 💡 如果 E 欄全部是 `#NAME?`，代表你的 Excel 版本沒有 XLOOKUP（2019 以前）。可以請 AI 改用 `INDEX`＋`MATCH`。

## 6️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 訂單裡直接寫名稱和單價 | C2 訂單明細 E、G 欄資料型態是「文字／數值」 | 「改成公式，從主檔查詢」 |
| 用 IFERROR 全部變 0 | `=IFERROR(XLOOKUP(…),0)` | 「名稱欄顯示查無此編號，讓錯誤看得見」 |
| 用 VLOOKUP 數欄號 | `=VLOOKUP(C2,產品主檔!A:E,4,FALSE)` | 「改用 XLOOKUP」 |
| 主檔編號重複 | 示範資料兩筆 `P-003` | 「主檔編號不可重複」 |
| 沒有錯誤測試值 | C7 編號全部正確 | 「放一筆主檔沒有的編號」 |
