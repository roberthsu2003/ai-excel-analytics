# 試算表規範書：業績獎金判定

> 依循：RTCCF 試算表規範書標準 v1｜版本：v1｜日期：2026-10-24

# Role
你是一位熟悉業務獎金制度與 Excel 邏輯函數的資料分析師，判斷規則必須集中在一張規則表，不寫死在公式裡。

# Task
建立業務人員季度業績表：自動算達成率，判斷是否達標、獎金等級與全勤加碼資格。
- 交付物：`業績獎金判定.xlsx`，共 2 張工作表

# Context
- 用途：每季結算業務獎金。
- 誰填寫：業務助理填入目標與實績；誰閱讀：業務主管、人資。
- 一列代表：**一位業務人員的一季業績**。
- 工作表清單：

| 工作表 | 角色 | 內容 |
| :--- | :--- | :--- |
| 業績 | 資料層 | 結構化表格 `T_Bonus`，12 位業務 |
| 獎金規則 | 參照層 | 各等級的達成率下限；改規則只改這張表 |

# Constraints

## C1 結構規則
1. 資料列不合併儲存格。
2. 資料中間不留空白列、空白欄。
3. 一格只放一件事。
4. 第 1 列為欄位名稱，資料從第 2 列開始。
5. 凍結窗格：業績表 `C2`。
6. 結構化表格：業績 `A1:J13`，名稱 `T_Bonus`。
7. **門檻數字不可寫死在公式中**，一律參照「獎金規則」工作表（絕對參照）。

## C2 欄位定義表

工作表：獎金規則

| 欄 | 欄位名稱 | 角色 | 資料型態 | 顯示格式 | 必填 | 說明 |
| :-: | :--- | :--- | :--- | :--- | :-: | :--- |

A7 寫出全勤加碼規則的文字說明。

## C3 公式

| 欄位 | 公式（以第 2 列為例） | 白話說明 |
| :--- | :--- | :--- |
| G 達成率 | `=E2/D2` | 實際 ÷ 目標 |
| H 是否達標 | `=IF(G2>='獎金規則'!$B$3,"達標","未達標")` | **IF**：條件成立給第一個答案，不成立給第二個 |
| I 獎金等級 | `=IFS(G2>='獎金規則'!$B$2,"A",G2>='獎金規則'!$B$3,"B",G2>='獎金規則'!$B$4,"C",TRUE,"無")` | **IFS**：由上往下檢查，第一個成立的就是答案；`TRUE` 代表「以上都不是」 |
| J 全勤加碼 | `=IF(AND(H2="達標",F2="是"),"是","否")` | **AND**：兩個條件都成立才是「是」 |

> 技術備註：IFS 是 Excel 2019 起的函數，產生檔案時須寫成 `_xlfn.IFS`，Excel 開啟後會顯示為 `IFS`。

## C7 示範資料
- 筆數：12 位業務，三個部門各 4 位。
- 刻意放入的**邊界測試值**（剛好等於門檻）：
  - E004 張志明：達成率**剛好 120%** → 應為 A。
  - E006 王俊傑：達成率**剛好 100%** → 應為「達標」、B，且全勤 → 加碼「是」。
  - E003 黃詩涵：達成率**剛好 80%** → 應為 C，未達標 → 加碼「否」（雖然全勤）。
- 預期結果：A 3 人、B 4 人、C 3 人、無 2 人；達標 7 人；全勤加碼 4 人（E001、E006、E007、E009）。
