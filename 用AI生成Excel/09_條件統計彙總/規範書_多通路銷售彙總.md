# 試算表規範書：多通路銷售彙總

> 依循：RTCCF 試算表規範書標準 v1｜版本：v1｜日期：2026-10-24

# Role
你是一位熟悉零售通路分析與 Excel 條件統計函數的資料分析師，彙總表全部用公式從明細計算。

# Task
建立第一季銷售明細與通路彙總：各通路的訂單筆數、銷售金額、平均客單價，以及「通路 × 月份」交叉彙總表。
- 交付物：`多通路銷售彙總.xlsx`，共 2 張工作表

# Context
- 用途：季度通路檢討會議。
- 誰填寫：系統匯出明細；誰閱讀：營運主管。
- 一列代表：**一筆訂單**。
- 工作表清單：

| 工作表 | 角色 | 內容 |
| :--- | :--- | :--- |
| 銷售明細 | 資料層 | 結構化表格 `T_Sales`，45 筆 |
| 通路彙總 | 展示層 | 上方：通路彙總（A1:D5）；下方：通路 × 月份矩陣（A7 起） |

# Constraints

## C1 結構規則
1. 資料列不合併儲存格。
2. 資料中間不留空白列、空白欄。
3. 一格只放一件事。
4. 第 1 列為欄位名稱，資料從第 2 列開始。
5. 凍結窗格：銷售明細 `A2`。
6. 結構化表格：`A1:E46`，名稱 `T_Sales`。
7. 彙總表的每一個數字都是公式；**不可把樞紐分析的結果貼成數值**。
8. 矩陣的月份表頭存成「每月 1 日」的**日期**，顯示為 `yyyy-mm`，公式用它計算月份範圍。

## C2 欄位定義表

工作表：銷售明細

| 欄 | 欄位名稱 | 角色 | 資料型態 | 顯示格式 | 必填 | 說明 |
| :-: | :--- | :--- | :--- | :--- | :-: | :--- |
| A | 訂單編號 | 標識 | 文字 | 通用 | ✔ | `S-0001` |
| B | 訂單日期 | 條件 | 日期 | `yyyy-mm-dd` | ✔ | 2026-01 ～ 2026-03 |
| C | 通路 | 條件 | 文字 | 通用 | ✔ | 門市、官網、電商平台 |
| D | 產品類別 | 條件 | 文字 | 通用 | ✔ | 電腦周邊、音訊、配件 |
| E | 銷售金額 | 指標 | 數值（整數） | `#,##0` | ✔ | 元 |

工作表：通路彙總

| 區塊 | 欄 | 內容 | 資料型態 | 顯示格式 |
| :--- | :--- | :--- | :--- | :--- |
| 通路彙總 A1:D5 | A | 通路（第 5 列：合計） | 文字 | 粗體 |
| | B | 訂單筆數 | 公式 | 通用 |
| | C | 銷售金額 | 公式 | `#,##0` |
| | D | 平均客單價 | 公式 | `#,##0` |
| 矩陣 A8:E11 | A | 通路 | 文字 | 粗體 |
| | B～D | 2026-01、2026-02、2026-03（表頭為日期） | 公式 | `#,##0` |
| | E | 合計 | 公式 | `#,##0` |

## C3 公式

| 儲存格 | 公式（以第 2 列、B9 為例） | 白話說明 |
| :--- | :--- | :--- |
| B2 訂單筆數 | `=COUNTIFS(T_Sales[通路],$A2)` | 數「通路 = 門市」的有幾筆 |
| C2 銷售金額 | `=SUMIFS(T_Sales[銷售金額],T_Sales[通路],$A2)` | 加總「通路 = 門市」的金額 |
| D2 平均客單價 | `=IF(B2=0,0,ROUND(C2/B2,0))` | 金額 ÷ 筆數，四捨五入到元 |
| B5:D5 合計 | `=SUM(B2:B4)`、`=SUM(C2:C4)`、`=IF(B5=0,0,ROUND(C5/B5,0))` | |
| B9 矩陣 | `=SUMIFS(T_Sales[銷售金額],T_Sales[通路],$A9,T_Sales[訂單日期],">="&B$8,T_Sales[訂單日期],"<"&EDATE(B$8,1))` | 三個條件同時成立：通路 = A9、日期 ≥ 當月 1 日、日期 < 下月 1 日 |
| E9 矩陣合計 | `=SUM(B9:D9)` | |

> 矩陣公式用**混合參照**：`$A9` 鎖欄（往右複製時通路不動）、`B$8` 鎖列（往下複製時月份不動）。

## C7 示範資料
- 45 筆（每月 15 筆），通路與類別隨機分布，以固定亂數種子產生，可重現。
- 預期結果：

| 通路 | 訂單筆數 | 銷售金額 | 平均客單價 | 1 月 | 2 月 | 3 月 |
| :--- | --: | --: | --: | --: | --: | --: |
| 門市 | 15 | 91,360 | 6,091 | 43,090 | 14,280 | 33,990 |
| 官網 | 12 | 107,410 | 8,951 | 41,920 | 9,200 | 56,290 |
| 電商平台 | 18 | 120,220 | 6,679 | 18,070 | 66,400 | 35,750 |
| 合計 | 45 | 318,990 | 7,089 | | | |

- 驗算重點：官網筆數最少（12 筆），平均客單價卻最高（8,951）；門市筆數比官網多，銷售金額反而最少。示範「筆數」和「金額」是兩件事。
