## 1. 檔案與畫面

想像你打開一個 `報價單.xlsx`，點了 `D2` 這一格：

> **名稱方塊** `D2`　｜　**資料編輯列** `fx  =B2*C2`

| ↓列號 ＼ 欄名→ | **A** | **B** | **C** | **D** |
| :-: | :-- | --: | --: | --: |
| **1** | 品名 | 單價 | 數量 | 小計 |
| **2** | 原子筆 | 20 | 3 | **`60`** ← 你點的格子 |
| **3** | 便利貼 | 45 | 2 | 90 |

> 畫面最下方：`[ 報價單 ]` `[ 統計 ]` ← **工作表標籤**，一個標籤就是一張工作表

| 名詞 | 英文 | 白話說明 | 在規範書哪裡出現 |
| :--- | :--- | :--- | :--- |
| **活頁簿** | Workbook | 一個 `.xlsx` 檔案 | Task：交付物 |
| **工作表** | Worksheet / Sheet | 檔案裡的一頁，下方標籤可切換 | Context：工作表清單 |
| **欄** | Column | **直的**，用英文字母 A、B、C 命名 | C2：「欄」那一行 |
| **列** | Row | **橫的**，用數字 1、2、3 命名 | C1：「資料從第 2 列開始」 |
| **儲存格** | Cell | 欄和列交叉的一格 | 全部 |
| **儲存格位址** | Cell Reference | 先寫欄再寫列，例如 `C2` | C3：公式裡的 `C2*D2` |
| **範圍** | Range | 一塊連續的儲存格，`A2:D11` 表示從 A2 到 D11 | C3、C4、C5 |
| **資料編輯列** | Formula Bar | 畫面上方 `fx` 那一條，顯示儲存格**真正的內容** | 驗收時用 |
| **欄位名稱／表頭** | Header | 第 1 列的標題，例如「單價」 | C2：欄位名稱 |

> 🔑 **最重要的一招：點一格，看資料編輯列。** 儲存格上顯示 `60`，編輯列可能是 `60`（填死的數字），也可能是 `=B2*C2`（公式）。之後每一課的觀察任務都會用到。

## 2. 值 vs. 顯示格式：看起來一樣，裡面不一樣

| 儲存格顯示 | 真正的值 | 顯示格式 | 能不能加總？ |
| :--- | :--- | :--- | :-: |
| `12,000` | 12000（數值） | `#,##0` 千分位 | ✅ |
| `12,000元` | "12,000元"（文字） | 無 | ❌ 加總為 0 |
| `5%` | 0.05（數值） | `0%` 百分比 | ✅ |
| `2026-03-02` | 一個日期 | `yyyy-mm-dd` | ✅ 可取月份 |
| `115.03.02` | "115.03.02"（文字） | 無 | ❌ 無法取月份 |

- **顯示格式**（Number Format）只決定「看起來的樣子」。
- 所以規範書 C2 會**分開寫**「資料型態」和「顯示格式」兩欄。

## 3. 資料型態（Data Type）

| 型態 | 例子 | Excel 預設對齊 | 什麼時候用 |
| :--- | :--- | :---: | :--- |
| **文字** | 林雨萱、收入、`0012` | 靠左 | 名稱、類別、**要保留前導 0 的編號** |
| **數值** | 1500、3.5 | 靠右 | 金額、數量、分數，要拿來計算的 |
| **日期** | 2026-03-02 | 靠右 | 要能排序、取月份、算天數的 |
| **百分比** | 5% | 靠右 | 稅率、達成率（其實是數值 0.05） |
| **邏輯值** | TRUE／FALSE | 置中 | 是否、通過與否 |

> ⚠️ **AI 最常犯的錯**：把日期存成文字、把金額存成文字（因為多打了「元」）。看規範書 C2 時，先檢查這兩件事。

## 4. 公式、函數與參照

| 名詞 | 說明 | 例子 |
| :--- | :--- | :--- |
| **公式** | Formula，以 `=` 開頭，會自動計算 | `=B2*C2` |
| **函數** | Function，Excel 內建的計算工具 | `SUM`、`AVERAGE`、`IF`、`XLOOKUP` |
| **引數** | Argument，函數括號裡給的東西 | `SUM(D2:D11)` 的 `D2:D11` |
| **相對參照** | 複製公式時會跟著移動 | `B2` 往下複製變 `B3` |
| **絕對參照** | 加 `$` 鎖住，複製時不動 | `$B$1` 永遠是 B1 |
| **活檔案** | 用公式算，改了資料會自動重算 | 小計格內容是 `=B2*C2` |
| **死檔案** | 填算好的數字，改了資料也不會變 | 小計格內容是 `60` |

## 5. 資料表的功能名詞

| 名詞 | 英文 | 白話說明 | 第幾課學 |
| :--- | :--- | :--- | :-: |
| **排序** | Sort | 依某欄由小到大或由大到小排 | 04 |
| **篩選** | Filter | 只顯示符合條件的列，例如只看研發部 | 04 |
| **凍結窗格** | Freeze Panes | 往下捲時表頭固定不動 | 01 |
| **合併儲存格** | Merge Cells | 把幾格合成一格。**資料列禁止使用**，否則無法排序篩選 | 04 |
| **結構化表格** | Excel Table | 把一塊資料變成「表格」，新增列時公式和範圍自動延伸 | 04 |
| **資料驗證** | Data Validation | 限制只能輸入某些值，例如下拉選單 | 06 |
| **條件式格式** | Conditional Formatting | 符合條件就自動變色，例如超支變紅 | 07 |
| **主檔** | Master Table | 存固定資料的表，例如產品編號對應單價 | 08 |
| **樞紐分析表** | PivotTable | 用拖拉的方式做分組統計 | 09 |
| **圖表** | Chart | 長條圖、折線圖、圓餅圖 | 11 |
| **儀表板** | Dashboard | 給主管一眼看懂的總覽頁 | 12 |

## 6. 工作表的三種角色：資料層、參照層、展示層

| 角色 | 放什麼 | 誰在讀 | 規則 |
| :--- | :--- | :--- | :--- |
| 📁 **資料層** | 每天新增的流水帳，例如每筆報銷 | 公式、篩選、樞紐分析 | 一列一筆、不合併、不放總計 |
| 📚 **參照層** | 不常改的對照表，例如產品單價 | 公式（XLOOKUP） | 每列有唯一編號 |
| 📊 **展示層** | 彙總、圖表、儀表板 | 主管、客戶 | 可以美化，數字都用公式從資料層抓 |

> 💡 規範書的 **Context → 工作表清單**會標出每張表是哪一層。看到「總計」寫在資料層最後一列下面，就是該退件的訊號。

## 7. 錯誤代碼：看到不要慌

| 代碼 | 意思 | 常見原因 |
| :--- | :--- | :--- |
| `#VALUE!` | 型態不對 | 拿文字去做數學運算，例如 `"3,500元" * 2` |
| `#N/A` | 找不到 | XLOOKUP 查不到這個編號 |
| `#REF!` | 參照不見了 | 公式指向的欄或工作表被刪掉 |
| `#DIV/0!` | 除以 0 | 分母是 0 或空白 |
| `#NAME?` | 不認得的名稱 | 函數名稱打錯，或舊版 Excel 沒有這個函數 |
| `#####` | 不是錯誤 | 欄太窄放不下，拉寬就好 |
