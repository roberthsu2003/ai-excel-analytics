## 1️⃣ 白話需求

> 「各部門都在 LINE 群組丟採購需求，日期有人寫民國、有人寫西元，價格有人寫 NT$、有人寫元。請幫我整理成一張可以加總的採購表。我要能對回原本是誰說的哪一句。」

使用時把 `素材_LINE採購訊息.txt` 一起交給 AI。

## 2️⃣ 這一課為什麼特別適合 AI？

| 手動 | AI |
| :--- | :--- |
| 10 則訊息一則一則看、複製、貼上 | 一次讀完、一次拆好 |
| 民國年要自己 +1911 | 自動轉換 |
| 「x6條」「@450」要自己判斷意思 | 依上下文理解 |

> ⚠️ **但 AI 也可能看錯。** 所以規範書要求三件事：原始訊息一字不改、每列有原始編號可以對回去、清洗規則寫清楚。**你的工作是抽查**。

## 3️⃣ 本課觀念在規範書哪裡

| 規範書位置 | 寫了什麼 |
| :--- | :--- |
| **Context 工作表清單** | 原始、清洗後、清洗規則分三張表 |
| **C1 第 3 條** | 數量與單位、部門與申請人各自一欄 |
| **C1 第 7、8 條** | 原始不可改；不確定的要寫出假設 |
| **C3** | 小計用公式，AI 不可自己算好填入 |
| **C7** | 6 種髒資料類型與出現位置 |
| **Format 第 3 條** | 要附逐筆對照，方便抽查 |

## 4️⃣ 打開 xlsx 觀察

- [ ] 「原始訊息」**B2** 與「清洗後」第 2 列對照：`115/3/2` → **2026-03-02**、`2台` → 數量 **2**／單位 **台**、`NT$6,500` → **6,500**。
- [ ] 「清洗後」**H 欄**單價全部靠右，是數值；**G 欄**單位靠左，是文字。
- [ ] 點 **I2**：`=F2*H2`，小計是公式。
- [ ] 抽查 **#2**「行銷部張雅晴：3/3 …」：部門、申請人拆開了嗎？日期是 2026-03-03 嗎？
- [ ] 打開「清洗規則」：每一種髒資料怎麼處理都寫在這裡，包括「沒寫年份視為 2026 年」這個**假設**。

## 5️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 直接覆蓋原始資料 | 只有一張清洗後的表 | 「保留原始訊息工作表，一字不改」 |
| 無法追溯 | 清洗後沒有原始編號 | 「加上原始編號欄」 |
| 數量和單位黏在一起 | 數量欄是「2台」 | 「數量放數值，單位另開一欄」 |
| 民國年沒轉 | 日期 0115-03-02 | 「民國年 + 1911」 |
| 默默猜測 | 沒寫年份的訊息沒有說明 | 「在清洗規則寫出假設」 |
| 小計自己算好 | 小計欄資料型態是「數值」 | 「小計用公式」 |
