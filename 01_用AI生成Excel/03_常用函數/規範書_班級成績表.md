# 試算表規範書：班級成績表

> 依循：RTCCF 試算表規範書標準 v1｜版本：v1｜日期：2026-10-24

# Role
你是一位熟悉學校成績處理與 Excel 統計函數的資料分析師，特別注意缺考（空白）不能被當成 0 分。

# Task
建立一個班級三科段考成績表：每位學生自動算總分、平均、已考科數；另一張表自動算各科平均、最高、最低、應考人數。
- 交付物：`班級成績表.xlsx`，共 2 張工作表

# Context
- 用途：導師整理段考成績、了解各科表現。
- 誰填寫：導師；誰閱讀：導師、科任老師。
- 一列代表：**一位學生的三科成績**。
- 工作表清單：

| 工作表 | 角色 | 內容 |
| :--- | :--- | :--- |
| 成績 | 資料層 | 20 位學生的成績與個人計算 |
| 各科統計 | 展示層 | 各科的統計結果，全部用公式從「成績」抓 |

# Constraints

## C1 結構規則
1. 資料列不合併儲存格。
2. 資料中間不留空白列、空白欄。
3. 一格只放一件事。
4. 第 1 列為欄位名稱，資料從第 2 列開始。
5. 凍結窗格：成績表凍結在 `C2`（座號、姓名與表頭固定）。
6. 結構化表格名稱：本課不適用（本課使用**固定範圍**；新增資料時要修改公式範圍，第 04 課起改用結構化表格）。
7. **缺考一律留空白，不可填 0**。

## C2 欄位定義表

工作表：成績

| 欄 | 欄位名稱 | 角色 | 資料型態 | 顯示格式 | 必填 | 說明 |
| :-: | :--- | :--- | :--- | :--- | :-: | :--- |
| A | 座號 | 標識 | 文字 | 文字（`@`） | ✔ | `01`～`20`，保留前導 0 |
| B | 姓名 | 標識 | 文字 | 通用 | ✔ | |
| C | 國文 | 指標 | 數值（整數） | 通用 | | 0～100，缺考留空 |
| D | 英文 | 指標 | 數值（整數） | 通用 | | 同上 |
| E | 數學 | 指標 | 數值（整數） | 通用 | | 同上 |
| F | 總分 | 指標 | 公式 | 通用 | ✔ | 見 C3 |
| G | 平均 | 指標 | 公式 | `0.0` | ✔ | 見 C3，四捨五入到小數 1 位 |
| H | 已考科數 | 指標 | 公式 | 通用 | ✔ | 見 C3 |

工作表：各科統計

| 欄 | 欄位名稱 | 角色 | 資料型態 | 顯示格式 | 必填 | 說明 |
| :-: | :--- | :--- | :--- | :--- | :-: | :--- |
| A | 統計項目 | 條件 | 文字 | 通用 | ✔ | 平均分數、最高分、最低分、應考人數、全班人數 |
| B～D | 國文、英文、數學 | 指標 | 公式 | 平均列 `0.0` | ✔ | 見 C3 |
| E | 使用的函數 | — | 文字 | 通用（灰色斜體） | ✔ | 教學說明 |

## C3 公式

| 欄位／儲存格 | 公式（以第 2 列或國文欄為例） | 白話說明 |
| :--- | :--- | :--- |
| 成績!F 總分 | `=SUM(C2:E2)` | 三科相加，空白不算 |
| 成績!G 平均 | `=ROUND(AVERAGE(C2:E2),1)` | 只平均有考的科目，四捨五入到 1 位 |
| 成績!H 已考科數 | `=COUNT(C2:E2)` | COUNT 只數「數字」，空白不算 |
| 各科統計 平均分數 | `=ROUND(AVERAGE('成績'!C2:C21),1)` | AVERAGE 自動略過空白 |
| 各科統計 最高分 | `=MAX('成績'!C2:C21)` | |
| 各科統計 最低分 | `=MIN('成績'!C2:C21)` | |
| 各科統計 應考人數 | `=COUNT('成績'!C2:C21)` | 有分數的人數 |
| 各科統計 全班人數 | `=COUNTA('成績'!B2:B21)` | COUNTA 數「非空白」的格子 |

## C4 資料驗證
本課不適用（第 06 課才加入分數 0～100 的限制）。

## C5 條件式格式
本課不適用。

## C6 版面與樣式
- 字型：微軟正黑體；表頭深藍底白字粗體置中。
- 各科統計 A 欄粗體；E 欄灰色斜體。
- 欄寬：成績 7、10、8、8、8、8、8、10；統計 12、9、9、9、22。

- 筆數：20 位學生。
- 刻意放入的測試值：

2. 等使用者回覆「確認」後，才依本規範書產生 `.xlsx`。
3. 交付 `.xlsx` 時附上驗收清單：公式位置、資料驗證位置、測試值位置。
