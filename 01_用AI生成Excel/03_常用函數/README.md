## 1️⃣ 白話需求

> 「我是導師，要整理全班 20 個人的國英數成績。每個人要有總分和平均，另外要看各科的平均、最高、最低分。有兩個同學缺考，缺考不能算 0 分。」

## 2️⃣ 七個函數，一次認識

| 函數 | 做什麼 | 遇到空白 | 在規範書哪裡 |
| :--- | :--- | :--- | :--- |
| `SUM` | 加總 | 略過 | C3 總分 |
| `AVERAGE` | 平均 | **略過**（不會當 0） | C3 平均 |
| `ROUND(值, 位數)` | 四捨五入 | — | C3 平均 |
| `MAX` | 最大值 | 略過 | C3 最高分 |
| `MIN` | 最小值 | 略過 | C3 最低分 |
| `COUNT` | 數有幾個**數字** | 不算 | C3 已考科數、應考人數 |
| `COUNTA` | 數有幾個**非空白** | 不算 | C3 全班人數 |

> 💡 你不用背函數怎麼寫。你要知道的是**什麼情況該用哪一個**，看規範書時才判斷得出 AI 有沒有用對。

## 3️⃣ 本課觀念在規範書哪裡

| 規範書位置 | 寫了什麼 | 為什麼重要 |
| :--- | :--- | :--- |
| **C1 第 7 條** | 缺考留空白，不可填 0 | 填 0 會把平均拉低 |
| **C2 A 欄** | 座號是「文字」 | 座號是標識，不拿來算 |
| **C3** | 每個統計格用哪個函數 | 用錯函數，數字就錯 |
| **Context 工作表清單** | 「成績」是資料層、「各科統計」是展示層 | 統計表全部用公式抓資料，不手打 |
| **C7 預期結果** | 每科平均、最高、最低 | 打開檔案對答案 |

## 4️⃣ 打開 xlsx 觀察

> ⬇️ **先下載檔案**：[班級成績表.xlsx](https://github.com/roberthsu2003/ai-excel-analytics/raw/main/01_%E7%94%A8AI%E7%94%9F%E6%88%90Excel/03_%E5%B8%B8%E7%94%A8%E5%87%BD%E6%95%B8/%E7%8F%AD%E7%B4%9A%E6%88%90%E7%B8%BE%E8%A1%A8.xlsx)。下載後用 Excel 打開；在 GitHub 網頁上預覽看不到公式和格式。

### 工作表「成績」
- [ ] 點 **F2**：`=SUM(C2:E2)`；點 **G2**：`=ROUND(AVERAGE(C2:E2),1)`。
- [ ] 看第 5 列 **張志明**：英文空白。總分 137、平均 **68.5**（只平均兩科）、已考科數 **2**。
- [ ] 想一想：如果英文填 0，平均會變成 45.7，對他公平嗎？

### 工作表「各科統計」
- [ ] 點 **B2**：`=ROUND(AVERAGE('成績'!C2:C21),1)`。`'成績'!` 表示「去成績那張表抓」。
- [ ] 對照：英文應考人數 **19**（COUNT 只數數字），全班人數 **20**（COUNTA 數姓名）。
- [ ] 把結果和規範書 C7 的預期結果表對一遍。

> 📏 **本課用的是固定範圍**：統計公式寫成 `'成績'!C2:C21`，剛好是 20 位學生。如果轉來第 21 位同學，每一個統計公式都要改成 `C2:C22`。第 04 課會學到**結構化表格**，新增資料不用重寫公式。

## 5️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 缺考填 0 | 示範資料缺考寫 `0` | 「缺考留空白」 |
| 平均自己除 | `=SUM(C2:E2)/3` | 「用 AVERAGE，缺考不算進分母」 |
| 人數用錯函數 | 應考人數用 `COUNTA` | 「有分數才算，用 COUNT」 |
| 統計表填死值 | C3 沒有各科統計的公式 | 「各科統計全部用公式從成績表計算」 |
