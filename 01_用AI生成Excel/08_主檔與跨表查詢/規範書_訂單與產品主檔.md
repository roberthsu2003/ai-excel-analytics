# 試算表規範書：訂單與產品主檔

> 依循：RTCCF 試算表規範書標準 v1｜版本：v1｜日期：2026-10-24

# Role
你是一位熟悉進銷存流程與 Excel 跨表查詢的資料分析師，訂單只記編號，名稱與單價一律由主檔查詢帶出。

# Task
建立訂單明細與產品主檔：訂單只輸入產品編號與數量，產品名稱、類別、單價用 XLOOKUP 自動帶出；查不到的編號要明確標示。
- 交付物：`訂單與產品主檔.xlsx`，共 3 張工作表

# Context
- 用途：記錄每日訂單、計算營收。
- 誰填寫：業務助理；誰閱讀：業務主管、會計。
- 一列代表：訂單明細＝**一張訂單的一個產品**；產品主檔＝**一個產品**。
- 工作表清單：

| 工作表 | 角色 | 內容 |
| :--- | :--- | :--- |
| 訂單明細 | 資料層 | 結構化表格 `T_Order` |
| 產品主檔 | 參照層 | 結構化表格 `T_Product`，產品編號不重複 |
| 訂單彙總 | 展示層 | 筆數、營收、查無編號筆數 |

# Constraints

## C1 結構規則
1. 資料列不合併儲存格。
2. 資料中間不留空白列、空白欄。
3. 一格只放一件事。
4. 第 1 列為欄位名稱，資料從第 2 列開始。
5. 凍結窗格：訂單明細、產品主檔都是 `A2`。
6. 結構化表格：`T_Order`（A1:H16）、`T_Product`（A1:E9）。
7. **訂單明細不可手打產品名稱、類別、單價**，一律由主檔查詢帶出（二要：拆主檔）。

## C2 欄位定義表

工作表：產品主檔

| 欄 | 欄位名稱 | 角色 | 資料型態 | 顯示格式 | 必填 | 說明 |
| :-: | :--- | :--- | :--- | :--- | :-: | :--- |
| A | 產品編號 | 標識 | 文字 | 通用 | ✔ | `P-001`，**不可重複** |
| B | 產品名稱 | 條件 | 文字 | 通用 | ✔ | |
| C | 類別 | 條件 | 文字 | 通用 | ✔ | |
| D | 單價 | 指標 | 數值（整數） | `#,##0` | ✔ | 售價 |
| E | 成本 | 指標 | 數值（整數） | `#,##0` | ✔ | 進貨成本 |

工作表：訂單明細

| 欄 | 欄位名稱 | 角色 | 資料型態 | 顯示格式 | 必填 | 說明 |

## C3 公式

| 欄位／儲存格 | 公式（以第 2 列為例） | 白話說明 |
| :--- | :--- | :--- |
| E 產品名稱 | `=XLOOKUP(C2,T_Product[產品編號],T_Product[產品名稱],"查無此編號")` | 拿 C2 去主檔的產品編號欄找，找到就回傳同一列的產品名稱；**找不到顯示「查無此編號」** |
| F 類別 | `=XLOOKUP(C2,T_Product[產品編號],T_Product[類別],"—")` | 同上，回傳類別 |
| G 單價 | `=XLOOKUP(C2,T_Product[產品編號],T_Product[單價],0)` | 找不到時單價 0，避免小計出現錯誤；E 欄會同時標示查無編號 |
| H 小計 | `=D2*G2` | 數量 × 單價 |
| 訂單彙總!B2 | `=COUNTA(T_Order[訂單編號])` | 訂單筆數 |
| 訂單彙總!B3 | `=SUM(T_Order[小計])` | 營收總計 |
| 訂單彙總!B4 | `=COUNTIF(T_Order[產品名稱],"查無此編號")` | 有幾筆編號打錯；**不是 0 就要回頭檢查** |

> 技術備註：XLOOKUP 是 Excel 2021／365 的函數，產生檔案時須寫成 `_xlfn.XLOOKUP`。

## C4 資料驗證
本課不適用（實務上可在 C 欄加上「清單 = 產品主檔編號」的下拉選單，請參考第 06 課）。

## C7 示範資料
- 產品主檔 8 項（P-001～P-008）；訂單 15 筆（2026-01-03 ～ 2026-01-30）。
- 刻意放入的測試值：**O-0006 產品編號 `P-999`**（主檔沒有）→ 產品名稱「查無此編號」、單價 0、整列紅底；訂單彙總的查無編號筆數 = 1。
- 預期結果：訂單筆數 15、營收總計 **112,710**。
