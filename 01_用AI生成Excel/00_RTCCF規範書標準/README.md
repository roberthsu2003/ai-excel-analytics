> [!IMPORTANT]
> **規範書是 AI 動手前的「施工圖」。** 你不需要會操作 Excel，但要看得懂這張圖：要幾張工作表、每欄放什麼、哪裡用公式、哪裡要防呆。
> 本課程每一份規範書都照這份標準寫，**標題一樣、順序一樣**。看過一份，就看得懂全部。

---

## 一、為什麼要有固定標準？

| 沒有標準 | 有標準 |
| :--- | :--- |
| 每次 AI 寫的規範書長得不一樣，不知道從哪裡看起 | 固定位置：想看公式就翻 **C3**，想看下拉選單就翻 **C4** |
| 漏寫了什麼也看不出來 | 某一節空白或寫「本課不適用」，一眼就知道 |
| 下次要改需求，要從頭講一遍 | 只要說「把 C2 第 D 欄改成日期」 |

## 二、RTCCF 五大段＋ C1～C7 七小節

RTCCF 是五個英文字的縮寫：**R**ole（角色）、**T**ask（任務）、**C**ontext（背景）、**C**onstraints（限制規格）、**F**ormat（輸出方式）。
其中 **Constraints** 是規範書的主體，固定拆成 C1～C7 七小節：

```
# Role          你（AI）扮演誰
# Task          要交付什麼
# Context       用途、使用者、「一列代表什麼」、工作表清單
# Constraints
  ## C1 結構規則
  ## C2 欄位定義表
  ## C3 公式
  ## C4 資料驗證
  ## C5 條件式格式
  ## C6 版面與樣式
  ## C7 示範資料
# Format        先交規範書 → 等「確認」→ 才產生 .xlsx
```

> 💡 **沒用到的小節也不能刪**，請寫「本課不適用」。這樣你一看就知道 AI 不是漏寫，而是本來就不需要。

## 三、逐節說明：每一節寫什麼、你要看什麼

### `# Role` 角色
告訴 AI 用什麼身分思考，例如「熟悉會計稽核與 Excel 資料結構的資料分析師」。
👀 **你要看**：角色和用途相符就好，不用細究。

### `# Task` 任務
一句話說要做什麼，再列出交付物（例如：一個 .xlsx，含 2 張工作表）。
👀 **你要看**：交付物的數量、檔名對不對。

### `# Context` 背景
| 必填項目 | 例子 |
| :--- | :--- |
| 用途 | 每月報帳，交財務審核 |
| 誰填、誰看 | 同仁填寫，會計審核 |
| **一列代表什麼** | 一筆報銷 |
| 工作表清單 | `報銷明細`（資料層）、`報銷彙總`（展示層） |

👀 **你要看**：「一列代表什麼」講得清楚嗎？工作表有沒有把**資料層**（存資料）和**展示層**（給人看）分開？→ 名詞見 [00 基本觀念・三層分工](../00_Excel基本觀念/README.md#6-工作表的三種角色資料層參照層展示層)

### `## C1 結構規則`
固定寫這幾條（依課程需要增加）：
1. 資料列不合併儲存格
2. 資料中間不留空白列、空白欄
3. 一格只放一件事
4. 第 1 列是欄位名稱，資料從第 2 列開始（有參數區時另外說明）
5. 凍結窗格位置
6. 結構化表格名稱（從第 04 課開始）

### `## C2 欄位定義表`（最重要）

固定 7 個欄位，不能少：

| 欄 | 欄位名稱 | 角色 | 資料型態 | 顯示格式 | 必填 | 說明 |
| :-: | :--- | :--- | :--- | :--- | :-: | :--- |
| A | 報銷日期 | 條件 | 日期 | `yyyy-mm-dd` | ✔ | 實際支出日 |
| B | 金額 | 指標 | 數值（整數） | `#,##0` | ✔ | 不可輸入「元」 |

- **角色**沿用第二部的三種：🟢**指標**（可加總的數字）、🔵**條件**（分組用的文字或日期）、⚪**標識**（編號，只能數筆數）。
- **資料型態**只能寫：文字、數值（整數／小數）、日期、百分比、公式。
- **顯示格式**是「看起來的樣子」，不改變儲存格裡真正的值。

👀 **你要看**：日期是不是寫「日期」而不是「文字」？金額是不是「數值」？編號（如收據編號 0012）是不是「文字」？

### `## C3 公式`

| 欄位／儲存格 | 公式 | 白話說明 |
| :--- | :--- | :--- |
| 小計 | `=C2*D2` | 單價 × 數量，向下每列都一樣 |

👀 **你要看**：凡是「算出來的」欄位都要出現在這張表；**不能有任何算好的數字直接填進去**。

### `## C4 資料驗證`

| 欄位 | 規則 | 錯誤訊息 |
| :--- | :--- | :--- |
| 收支類別 | 下拉選單：收入、支出 | 請從選單中選擇 |

### `## C5 條件式格式`

| 範圍 | 條件 | 樣式 |
| :--- | :--- | :--- |
| 剩餘預算 | 小於 0 | 紅字、淡紅底 |

### `## C6 版面與樣式`
欄寬、字型、表頭顏色、數字對齊方式。這節影響「好不好看」，不影響「對不對」。

### `## C7 示範資料`
- 要幾筆、涵蓋哪些情境
- **刻意放進去的測試值**（例如一筆缺考、一筆超支），讓你打開檔案時可以驗證公式和警示有沒有作用

### `# Format` 輸出方式（固定三段式）
```
1. 只輸出本規範書（Markdown），先不要產生 Excel。
2. 等使用者回覆「確認」後才產生 .xlsx。
3. 交付 .xlsx 時附上驗收清單：哪幾格是公式、哪幾格有驗證、測試值在哪裡。
```
