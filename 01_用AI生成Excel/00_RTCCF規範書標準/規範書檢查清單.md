# ✅ 規範書檢查清單

> AI 交出規範書後，**先別急著說「確認」**。照下面逐項打勾，全部打勾才回覆「確認」；有一項不行，就請 AI 修改那一節。

## 1. 結構有沒有齊全？
- [ ] 有 `# Role`、`# Task`、`# Context`、`# Constraints`、`# Format` 五大段
- [ ] Constraints 內有 C1～C7 七小節（沒用到的寫「本課不適用」）

## 2. Context：想清楚了嗎？
- [ ] 寫出「**一列代表什麼**」
- [ ] 存資料的工作表（資料層）和給人看的工作表（展示層）有分開

## 3. C1 結構規則
- [ ] 寫明「資料列不合併儲存格」
- [ ] 寫明「資料中間不留空白列」
- [ ] 總計、合計**不緊貼在資料最後一列下面**（放上方參數區或另一張工作表）
- [ ] 會持續新增資料的表，設為**結構化表格**（有表格名稱），新增一筆不用重寫公式

## 4. C2 欄位定義表（最常出錯）
- [ ] 每一欄都有：欄、欄位名稱、角色、資料型態、顯示格式、必填、說明
- [ ] 日期欄的資料型態是「**日期**」，不是「文字」
- [ ] 金額、數量的資料型態是「**數值**」，說明裡寫「不可輸入元、NT$」
- [ ] 要保留前導 0 的編號（如 0012、電話）是「**文字**」
- [ ] 一格只放一件事（沒有「姓名＋電話」擠在同一欄）

## 5. C3 公式
- [ ] 所有「算出來的」欄位都列在 C3，沒有直接填死的數字
- [ ] 參照固定儲存格（稅率、匯率）時使用 `$` 絕對參照
- [ ] 表格裡的每列公式用 `[@欄位]` 寫法，並設為**計算欄位**
- [ ] 加總、統計用 `表格[欄位]`，沒有 `I2:I11` 這種寫死的範圍

## 6. C4／C5 防呆與警示（第 06 課起）
- [ ] 只能從固定選項挑的欄位有下拉選單
- [ ] 需要提醒的狀況（超支、逾期）有條件式格式

## 7. C7 示範資料
- [ ] 筆數和情境合理
- [ ] 有刻意放入的測試值，而且寫出它在哪一列、應該出現什麼結果

## 8. Format
- [ ] 寫明「先交規範書，確認後才產生 .xlsx」
- [ ] 寫明交付時要附驗收清單

---

全部打勾 ➜ 回覆 AI：**「規範書確認，請完全依照規範書產生 .xlsx，並附驗收清單。」**
