## 1️⃣ 白話需求

> 「做一張請假登記表。以前大家假別亂寫，有人寫『特休』、有人寫『特別休假』、有人寫『休假』，人資根本沒辦法統計。日期也有人填錯年份，結束日還比開始日早。」

## 2️⃣ 為什麼要防呆？

| 沒有防呆 | 有防呆 |
| :--- | :--- |
| 「特休」「特別休假」「休假」三種寫法，統計時被當成 3 種假 | 只能從選單選「特休」 |
| 請假 20 天也沒人發現 | 輸入 20 時直接跳出錯誤訊息 |
| 事後才發現錯，要一筆一筆改 | 輸入的當下就擋住 |

> 💡 **防呆是第二部「條件欄位」的保護者**。第二部要依「假別」分組統計時，假別的寫法必須一致才分得對。

## 3️⃣ 本課觀念在規範書哪裡

| 規範書位置 | 寫了什麼 |
| :--- | :--- |
| **Context** | 「選項清單」是參照層，選項集中管理 |
| **C1 第 7 條** | 驗證套用到第 200 列，新資料也受保護 |
| **C4** | 6 條驗證規則：3 個清單、1 個日期範圍、1 個自訂公式、1 個數值範圍 |
| **C7** | 示範資料全部合法，另外列出可以試著輸入的錯誤值 |

## 4️⃣ 打開 xlsx 觀察

> ⬇️ **先下載檔案**：[請假申請表.xlsx](https://github.com/roberthsu2003/ai-excel-analytics/raw/main/01_%E7%94%A8AI%E7%94%9F%E6%88%90Excel/06_%E8%B3%87%E6%96%99%E9%A9%97%E8%AD%89/%E8%AB%8B%E5%81%87%E7%94%B3%E8%AB%8B%E8%A1%A8.xlsx)。下載後用 Excel 打開；在 GitHub 網頁上預覽看不到公式和格式。

> 這一課要「點一下」才看得到效果，但**不用修改任何資料**。

- [ ] 點 **E2**（假別）：右邊出現 ▼ 小箭頭，旁邊有黃色提示框「請從下拉選單選擇假別」。
- [ ] 點 ▼：選項正是「選項清單」工作表 B 欄的 6 種假別。
- [ ] 點 **H4**：提示「以 0.5 天為單位，最多 14 天」。L-003 是半天事假 0.5。
- [ ] 點 **G2**：提示「結束日期不可早於開始日期」。
- [ ] 切到「選項清單」：三種選項各自一欄，要新增假別只要改這裡。

> 🧪 **想親眼看到被擋下來？** 可以在**空白的第 12 列** E12 輸入「颱風假」、H12 輸入 20，會跳出錯誤訊息。看完按「取消」，或關閉檔案時不要存檔。

## 5️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 選項寫死在驗證裡 | 清單寫 `特休,事假,病假` | 「選項放到選項清單工作表，驗證參照那個範圍」 |
| 只套用到現有資料 | 範圍 `E2:E11` | 「套用到第 200 列」 |
| 沒有錯誤訊息 | C4 只有規則欄 | 「每條都要有提示訊息與錯誤訊息」 |
| 錯誤樣式是「警告」 | 「樣式：警告／資訊」 | 「樣式：停止，才會真的擋下來」 |
