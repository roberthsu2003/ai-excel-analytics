# 試算表規範書：請假申請表

> 依循：RTCCF 試算表規範書標準 v1｜版本：v1｜日期：2026-10-24

# Role
你是一位熟悉人資請假流程與 Excel 資料驗證（防呆）的資料分析師，目標是讓填寫的人「填不錯」。

# Task
建立請假申請紀錄表：部門、假別、審核狀態只能從下拉選單選；日期與天數有範圍限制；結束日期不可早於開始日期。
- 交付物：`請假申請表.xlsx`，共 2 張工作表

# Context
- 用途：同仁登記請假，人資統計。
- 誰填寫：同仁、主管（審核狀態）；誰閱讀：人資。
- 一列代表：**一筆請假申請**。
- 工作表清單：

| 工作表 | 角色 | 內容 |
| :--- | :--- | :--- |
| 請假紀錄 | 資料層 | 結構化表格 `T_Leave` |
| 選項清單 | 參照層 | 下拉選單的選項來源；要新增假別只改這裡 |

# Constraints

## C1 結構規則
1. 資料列不合併儲存格。
2. 資料中間不留空白列、空白欄。
3. 一格只放一件事。
4. 第 1 列為欄位名稱，資料從第 2 列開始。
5. 凍結窗格：`A2`。
6. 結構化表格：`A1:J11`，名稱 `T_Leave`。
7. 資料驗證套用到**第 2～200 列**，之後新增的資料也受保護。

## C3 公式
本課不適用（請假天數由申請人填寫，用資料驗證限制範圍）。

## C4 資料驗證

每條驗證都要設定「提示訊息」（點到格子時出現）與「錯誤訊息」（輸入錯誤時擋下，樣式：停止）。

| 範圍 | 規則 | 提示訊息 | 錯誤訊息 |
| :--- | :--- | :--- | :--- |
| D2:D200 部門 | 清單：`='選項清單'!$A$2:$A$6` | 請從下拉選單選擇部門 | 部門只能從選單中選擇 |
| E2:E200 假別 | 清單：`='選項清單'!$B$2:$B$7` | 請從下拉選單選擇假別 | 假別只能從選單中選擇 |
| I2:I200 審核狀態 | 清單：`='選項清單'!$C$2:$C$4` | 待審核／核准／駁回 | 審核狀態只能從選單中選擇 |
| F2:F200 開始日期 | 日期，介於 `DATE(2026,1,1)` 與 `DATE(2026,12,31)` | 請輸入 2026 年的日期 | 開始日期必須在 2026-01-01 ～ 2026-12-31 之間 |
| G2:G200 結束日期 | 自訂公式：`=G2>=F2` | 結束日期不可早於開始日期 | 結束日期不可早於開始日期 |
| H2:H200 請假天數 | 小數，介於 0.5 與 14 | 以 0.5 天為單位，最多 14 天 | 請假天數必須介於 0.5 ～ 14 天 |

## C5 條件式格式
本課不適用。

## C6 版面與樣式
- 字型：微軟正黑體；表頭由表格樣式提供。
- 欄寬：10、12、10、9、8、12、12、10、10、22。

## C7 示範資料
- 筆數：10 筆（2026-03-02 ～ 2026-03-25），6 種假別都至少出現一次。
- 涵蓋情境：半天事假（0.5 天）、連續 5 天特休、事後補請病假（開始日期早於申請日期，合法）、被駁回的申請（備註寫原因）。
- 測試方式：資料驗證會擋住「新輸入」的錯誤值，所以示範資料全部合法；請在驗收清單中列出可以嘗試輸入的錯誤值（例如假別輸入「颱風假」、天數輸入 20）。

# Format
1. 只輸出本規範書（Markdown），先不要產生 Excel。
2. 等使用者回覆「確認」後，才依本規範書產生 `.xlsx`。
3. 交付 `.xlsx` 時附上驗收清單：公式位置、資料驗證位置、測試值位置。
