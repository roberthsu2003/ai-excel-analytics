## 1️⃣ 白話需求

> 「幫我算業務的獎金等級：達成率 120% 以上是 A、100% 以上是 B、80% 以上是 C，其他沒有。達標而且全勤的人再加碼。規則以後可能會調整。」

「規則以後可能會調整」就是在提醒 AI：**門檻放在規則表，不要寫死在公式裡**（第 02 課的參數格觀念）。

## 2️⃣ 三個邏輯函數

| 函數 | 白話 | 例子 |
| :--- | :--- | :--- |
| `IF(條件, 成立時, 不成立時)` | 如果…就…否則… | 達成率 ≥ 100% 就「達標」，否則「未達標」 |
| `IFS(條件1, 答案1, 條件2, 答案2, …)` | 由上往下，第一個成立的就是答案 | ≥120% 是 A、≥100% 是 B… |
| `AND(條件1, 條件2)` | 全部都要成立 | 達標**而且**全勤 |
| `OR(條件1, 條件2)` | 任一個成立就好 | （本課沒用到，同一類函數） |

> ⚠️ **IFS 的順序很重要**：要從最高門檻往下寫。如果先寫「≥80% 是 C」，達成率 125% 的人也會先被判成 C。

## 3️⃣ 本課觀念在規範書哪裡

| 規範書位置 | 寫了什麼 |

## 4️⃣ 打開 xlsx 觀察

> ⬇️ **先下載檔案**：[業績獎金判定.xlsx](https://github.com/roberthsu2003/ai-excel-analytics/raw/main/01_%E7%94%A8AI%E7%94%9F%E6%88%90Excel/05_%E9%82%8F%E8%BC%AF%E5%88%A4%E6%96%B7/%E6%A5%AD%E7%B8%BE%E7%8D%8E%E9%87%91%E5%88%A4%E5%AE%9A.xlsx)。下載後用 Excel 打開；在 GitHub 網頁上預覽看不到公式和格式。

- [ ] 點 **I2**：公式裡有 `'獎金規則'!$B$2`。門檻是從規則表抓的，不是寫死的 1.2。
- [ ] 看 **E004 張志明**（第 5 列）：達成率 120.0%，等級 **A**。`>=` 包含「剛好等於」。
- [ ] 看 **E006 王俊傑**（第 7 列）：剛好 100%，達標、B、全勤 → 加碼「是」。
- [ ] 看 **E003 黃詩涵**（第 4 列）：剛好 80%，等級 C；有全勤但**未達標**，所以加碼「否」。這就是 AND。
- [ ] 用表頭篩選「獎金等級」：A 3 人、B 4 人、C 3 人、無 2 人。

> 💡 如果你的 Excel 是 2016 以前的版本，I 欄會顯示 `#NAME?`，因為舊版沒有 IFS。這時可以請 AI 改用「巢狀 IF」。

## 5️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 門檻寫死 | `=IFS([@達成率]>=1.2,"A",…)` | 「門檻放規則表，用 `$` 參照」 |
| 順序寫反 | IFS 先寫 0.8 | 「由高門檻往低門檻寫」 |
| 漏了「其他」 | IFS 最後沒有 `TRUE,"無"` | 「加上 TRUE,"無"，否則未滿 80% 會顯示 #N/A」 |
| 用 `>` 不是 `>=` | 剛好 100% 變成未達標 | 「門檻包含等於，用 >=」 |
| 沒有邊界測試 | C7 只有一般資料 | 「加入剛好等於門檻的測試值」 |
