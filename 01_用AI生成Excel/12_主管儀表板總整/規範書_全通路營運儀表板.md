# 試算表規範書：全通路營運儀表板

> 依循：RTCCF 試算表規範書標準 v1｜版本：v1｜日期：2026-10-24

# Role
你是一位熟悉經營分析與 Excel 儀表板設計的資料分析師，儀表板上的每個數字都必須能追溯到明細。

# Task
用第一季 60 筆銷售明細，建立給主管的一頁式儀表板：4 張 KPI 卡片、2 張圖表、3 點重點與 1 點限制。
- 交付物：`全通路營運儀表板.xlsx`，共 3 張工作表、2 張圖表

# Context
- 用途：季度經營會議，主管 30 秒看懂本季表現。
- 誰填寫：系統匯出明細；誰閱讀：總經理、各通路主管。
- 一列代表：**一筆訂單**。
- 工作表清單（依順序）：

| 工作表 | 角色 | 內容 |
| :--- | :--- | :--- |
| 儀表板 | 展示層 | KPI 卡片、圖表、重點文字 |
| 計算 | 展示層（圖表資料） | 每月、每通路的 SUMIFS 彙總 |
| 銷售明細 | 資料層 | 結構化表格 `T_Sales12`，60 筆 |

# Constraints

## C1 結構規則
1. **資料層**（銷售明細、計算）不合併儲存格；**只有儀表板允許合併**（標題與 KPI 卡片）。
2. 資料中間不留空白列、空白欄。
3. 一格只放一件事。
4. 銷售明細第 1 列為欄位名稱，資料從第 2 列開始；凍結 `A2`。
5. 結構化表格：`A1:G61`，名稱 `T_Sales12`；G 欄「毛利」設為計算欄位。
6. **儀表板上不可出現任何手打的數字**：KPI 是公式、圖表資料來自「計算」工作表。
7. 重點文字必須與數字一致，並寫出至少 1 點資料限制。

## C2 欄位定義表

## C3 公式

| 位置 | 公式 | 白話說明 |
| :--- | :--- | :--- |
| 銷售明細!G 毛利 | `=[@銷售金額]-[@成本]`（計算欄位） | 毛利 = 銷售金額 − 成本；新增訂單自動帶出 |
| 計算!B2 | `=SUMIFS(T_Sales12[銷售金額],T_Sales12[訂單日期],">="&$A2,T_Sales12[訂單日期],"<"&EDATE($A2,1))` | 當月營收 |
| 計算!C2 | 同上，加總 `T_Sales12[毛利]` | 當月毛利 |
| 計算!B8 | `=SUMIFS(T_Sales12[銷售金額],T_Sales12[通路],$A8)` | 通路營收 |
| 計算!D8 | `=IF(B8=0,0,C8/B8)` | 通路毛利率 |
| 儀表板!A4 總營收 | `=SUM(T_Sales12[銷售金額])` | |
| 儀表板!D4 總毛利 | `=SUM(T_Sales12[毛利])` | |
| 儀表板!G4 毛利率 | `=IF(SUM(T_Sales12[銷售金額])=0,0,SUM(T_Sales12[毛利])/SUM(T_Sales12[銷售金額]))` | 格式 `0.0%` |
| 儀表板!J4 訂單筆數 | `=COUNTA(T_Sales12[訂單編號])` | |

## C6 版面與樣式（圖表規格）

| # | 問題 | 圖表 | 資料來源 | 標題 | 軸 | 位置 |
| :-: | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 每月營收怎麼變化？（只有 3 個時間點） | 直條圖 | 計算 A1:B4 | 每月營收 | X 月份；Y 營收（元），從 0 開始 | A7 |
| 2 | 哪個通路賺最多？ | 橫條圖（營收、毛利兩數列） | 計算 A7:C10 | 各通路營收與毛利 | X 通路；Y 金額（元），從 0 開始 | G7 |

- 只有 3 個時間點，依第二部規則用直條圖而不是折線圖。
- 配色：深藍 `#1F4E79` 為主色，KPI 卡片淡藍底 `#DDEBF7`；不使用 3D 與彩虹配色。
- 儀表板欄寬一律 9，讓卡片等寬。

## C7 示範資料
- 60 筆（每月 20 筆），成本約為銷售金額的 52%～72%，以固定亂數種子產生，可重現。
- 預期 KPI：總營收 **511,650**、總毛利 **201,350**、毛利率 **39.4%**、訂單筆數 **60**。
- 預期重點文字：
  1. 營收最高的月份是 2 月（175,560 元）。
  2. 營收最高的通路是電商平台（191,030 元）。
  3. 毛利率最高的通路是門市（40.8%）。
  - 限制：只有一季資料，不能推論長期趨勢；毛利未扣除運費與人事成本。
