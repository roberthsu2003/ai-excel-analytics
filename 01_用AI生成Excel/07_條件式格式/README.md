## 1️⃣ 白話需求

> 「專案會議時，主管想一眼看出哪些任務超支、哪些過了截止日還沒做完。完成的可以標綠色，進度最好有長條可以看。」

## 2️⃣ 防呆 vs. 警示

| | 第 06 課 資料驗證 | 第 07 課 條件式格式 |
| :--- | :--- | :--- |
| 時機 | 輸入**當下** | 資料**已經在表裡** |
| 作用 | 擋住錯的值 | 把要注意的值標出來 |
| 例子 | 天數不能超過 14 | 超支變紅色 |

> 💡 **手動上色 vs. 條件式格式**：手動塗紅的格子，支出改了也不會變回來；條件式格式是「規則」，資料一變，顏色就跟著變。

| 規範書位置 | 寫了什麼 |

## 4️⃣ 打開 xlsx 觀察

> ⬇️ **先下載檔案**：[專案進度管控表.xlsx](https://github.com/roberthsu2003/ai-excel-analytics/raw/main/01_%E7%94%A8AI%E7%94%9F%E6%88%90Excel/07_%E6%A2%9D%E4%BB%B6%E5%BC%8F%E6%A0%BC%E5%BC%8F/%E5%B0%88%E6%A1%88%E9%80%B2%E5%BA%A6%E7%AE%A1%E6%8E%A7%E8%A1%A8.xlsx)。下載後用 Excel 打開；在 GitHub 網頁上預覽看不到公式和格式。

- [ ] 看 **I 欄**：T-02、T-05、T-11 的剩餘預算是**紅色**負數。
- [ ] 看 **T-03、T-06** 整列：**黃底**，已過 2026-04-15 但還在進行中。
- [ ] 看 **T-01**：截止日也過了，但狀態「已完成」，所以**沒有**變黃。這就是 AND 的作用。
- [ ] 看 **E 欄**：「已完成」是綠色。
- [ ] 看 **F 欄**：藍色資料橫條，長度就是完成進度。
- [ ] 想觀察規則本身：點 A2，到「常用 → 條件式格式設定 → 管理規則」**只看不改**，可以看到 4 條規則。
- [ ] 切到「設定」：基準日 2026-04-15。如果改成 `=TODAY()`，每天打開時逾期的任務都會自動更新。

## 5️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 直接手動塗色 | C5 寫「T-02 列塗紅」 | 「用條件式格式規則，不要手動上色」 |
| 整列上色只有一格變色 | 範圍寫 `D2:D13` | 「範圍 A2:J200，公式用 `$D2`」 |
| 鎖錯參照 | 公式 `=$D$2<基準日` | 「改成 `$D2`，鎖欄不鎖列」 |
| 完成的也標逾期 | 條件只有 `$D2<基準日` | 「加上 AND 狀態不是已完成」 |
| 用 TODAY() 讓教材每天不同 | C5 直接寫 `TODAY()` | 「教材用固定基準日，實務再換 TODAY()」 |
