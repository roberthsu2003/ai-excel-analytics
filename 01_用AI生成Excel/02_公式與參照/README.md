## 1️⃣ 白話需求

> 「幫我做一張文具報價單，每個品項有單價和數量，要自動算小計、5% 營業稅和含稅金額，最上面要有總額。稅率以後可能會改，改一個地方就好。」

最後一句「改一個地方就好」是關鍵。AI 會因此規劃一個**稅率參數格**，並用 **`$` 絕對參照**鎖住它。

## 2️⃣ 本課觀念在規範書哪裡

| 規範書位置 | 寫了什麼 | 為什麼重要 |
| :--- | :--- | :--- |
| **C1 第 4 條** | 參數區在上、明細在下，合計不貼在明細尾巴 | 之後新增品項不會蓋到合計 |
| **C2 參數區 B1** | 稅率存成百分比 0.05 | 改這一格，全表重算 |
| **C3 E 小計** | `=C7*D7`（相對參照） | 往下複製自動變成 C8*D8 |
| **C3 F 稅額** | `=ROUND(E7*$B$1,0)`（絕對參照） | 往下複製時稅率永遠指向 B1 |
| **C7 預期結果** | 10,625／532／11,157 | 打開檔案時可以對答案 |

### 相對參照 vs. 絕對參照

| 第 7 列寫的公式 | 複製到第 8 列變成 | 複製到第 9 列變成 |
| :--- | :--- | :--- |
| `=C7*D7` | `=C8*D8` | `=C9*D9` ✅ 該跟著動 |
| `=E7*$B$1` | `=E8*$B$1` | `=E9*$B$1` ✅ 稅率不動 |
| `=E7*B1` ❌ | `=E8*B2` | `=E9*B3` ❌ 稅率跑掉了 |

## 3️⃣ 打開 xlsx 觀察

> ⬇️ **先下載檔案**：[商品報價單.xlsx](https://github.com/roberthsu2003/ai-excel-analytics/raw/main/01_%E7%94%A8AI%E7%94%9F%E6%88%90Excel/02_%E5%85%AC%E5%BC%8F%E8%88%87%E5%8F%83%E7%85%A7/%E5%95%86%E5%93%81%E5%A0%B1%E5%83%B9%E5%96%AE.xlsx)。下載後用 Excel 打開；在 GitHub 網頁上預覽看不到公式和格式。

### 工作表「報價單」
- [ ] 點 **E7**：資料編輯列是 `=C7*D7`。再點 **E8**：變成 `=C8*D8`。
- [ ] 點 **F7**、**F8**、**F14**：每一格都有 `$B$1`。
- [ ] 看 **B2～B4**：未稅合計 10,625、稅額合計 532、含稅總額 11,157。
- [ ] 點 **B2**：公式是 `=SUM(E7:E14)`。合計是從明細**算出來的**。

### 工作表「錯誤示範_相對參照」
- [ ] 點 **F7**：`=ROUND(E7*B1,0)`，第一列看起來正常。
- [ ] 點 **F8**：`=ROUND(E8*B2,0)`。B2 是空白格，所以 F8～F11 的稅額都變成 **0**。
- [ ] 點 **F12**：`=ROUND(E12*B6,0)`。B6 是表頭文字「品名」，所以 F12～F14 變成 **`#VALUE!`**，含稅金額也跟著出錯。
- [ ] 這張錯誤示範表故意沒放合計。錯位的參照如果碰到合計格，會變成「循環參照」，Excel 開檔時就會跳出警告。

> 💡 這就是為什麼審規範書時要看 C3：**參照固定格子的公式，一定要有 `$`**。

> 📏 **本課用的是固定範圍**：合計寫成 `=SUM(E7:E14)`，只涵蓋現在的 8 個品項。如果新增第 9 個品項，就要回頭把範圍改成 `E7:E15`。第 04 課會學到**結構化表格**，新增資料不用重寫公式。

## 4️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 稅率寫死在公式裡 | `=E7*0.05` | 「稅率放參數格 B1，公式用 `$B$1`」 |
| 稅率沒鎖住 | `=E7*B1` | 「改成 `$B$1` 絕對參照」 |
| 合計填死數字 | C3 沒有 B2～B4，示範資料直接寫 10625 | 「合計改用 SUM 公式」 |
| 合計貼在明細尾巴 | C1 寫「第 15 列為合計」 | 「合計移到上方參數區」 |
