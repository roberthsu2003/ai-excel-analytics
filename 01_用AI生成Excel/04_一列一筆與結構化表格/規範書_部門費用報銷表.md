# 試算表規範書：部門費用報銷表

> 依循：RTCCF 試算表規範書標準 v1｜版本：v1｜日期：2026-10-24

# Role
你是一位熟悉會計稽核與 Excel 資料庫式結構的資料分析師，確保表格能直接排序、篩選與樞紐分析。

# Task
建立每月報帳用的費用報銷表：明細設為 Excel 結構化表格，新增報銷時公式與彙總自動延伸；彙總放在另一張工作表。另附一張「固定範圍對照」，示範一般範圍新增資料後總計漏算。
- 交付物：`部門費用報銷表.xlsx`，共 3 張工作表

# Context
- 用途：同仁每月報帳，財務審核。
- 誰填寫：各部門同仁；誰閱讀：財務、部門主管。
- 一列代表：**一筆報銷**。
- 工作表清單：

| 工作表 | 角色 | 內容 |
| :--- | :--- | :--- |
| 報銷明細 | 資料層 | 結構化表格 `T_Expense`，只放報銷資料 |
| 報銷彙總 | 展示層 | 筆數、總計、最大單筆，全部用公式從 `T_Expense` 計算 |
| 固定範圍對照 | 展示層（教學用） | 同樣資料放在一般範圍並多一筆，示範 `=SUM(I2:I11)` 漏算 |

# Constraints

## C1 結構規則（四不二要）
1. **不合併**：資料列不合併儲存格。
2. **不留空**：資料中間不留空白列、空白欄。
3. **一格一事**：金額、數量、發票號碼各自一欄。
4. **一維表**：第 1 列是欄位名稱，資料從第 2 列開始，**標題文字、總計都不放在這張表**。
5. **要唯一編號**：報銷序號 `EXP-2026-001` 不重複。
6. 凍結窗格：`A2`。
7. 結構化表格：範圍 `A1:K11`，名稱 **`T_Expense`**，樣式 TableStyleMedium2（斑馬紋），表頭自帶篩選按鈕。
8. **計算欄位**：I 欄「小計金額」設為表格計算欄位，新增列時自動帶出公式。

## C3 公式

| 欄位／儲存格 | 公式 | 白話說明 |
| :--- | :--- | :--- |
| 報銷明細!I 小計金額 | `=[@單價]*[@數量]`（計算欄位） | 同一列的單價 × 數量；新增列自動帶出 |
| 報銷彙總!B2 報銷筆數 | `=COUNTA(T_Expense[報銷序號])` | 數表格裡有幾筆 |
| 報銷彙總!B3 報銷總計金額 | `=SUM(T_Expense[小計金額])` | **結構化參照**：表格長大，範圍跟著長 |
| 報銷彙總!B4 最大單筆金額 | `=MAX(T_Expense[小計金額])` | |
| 固定範圍對照!I 小計金額 | `=G2*H2`（一般範圍，向下每列） | 對照組：一般範圍的寫法 |
| 固定範圍對照!N2 | `=SUM(I2:I11)` | 10 筆時寫的總計，**範圍寫死**，漏算第 12 列 |
| 固定範圍對照!N3 | `=SUM(I2:I12)` | 實際應有的總計 |
| 固定範圍對照!N4 | `=N3-N2` | 漏算的金額 |

> 計算欄位：寫在表格裡的公式用 `[@欄位]`（同一列的欄位），並設成表格的**計算欄位**；新增列時 Excel 自動帶出公式，不必重寫。檔案內實際存成 `表格[[#This Row],[欄位]]`。
