## 1️⃣ 白話需求

> 「做一份每月報帳用的報銷表，給同仁填、給會計審。以前大家亂合併儲存格，會計沒辦法篩選部門；總計又放在最下面，有人新增一筆就蓋掉了。這次請做成可以一直往下加的表。」

## 2️⃣ 四不二要

| | 規則 | 違反時會怎樣 |
| :-: | :--- | :--- |
| 🚫 | **不合併**儲存格 | 篩選、排序跳出錯誤：「合併儲存格必須大小相同」 |
| 🚫 | **不留空**白列 | Excel 以為資料到空白列就結束 |
| 🚫 | **不塞多件事**在一格 | `王小明 0912-345678` 無法依電話查詢 |
| 🚫 | **不把月份當欄名** | 「1月、2月、3月」橫著排，下個月就要改表 |
| ✅ | **要唯一編號** | 同名同姓時分不出是哪一筆 |
| ✅ | **要拆主檔** | 每列重打產品名稱，總有一筆打錯（第 08 課） |

## 3️⃣ 固定範圍 vs. 結構化表格：新增一筆時差在哪？

Excel 的資料有兩種放法。第 01～03 課用的是**一般範圍**，從這一課開始，資料層一律用**結構化表格**。

| 新增第 11 筆報銷時 | 一般範圍（固定） | 結構化表格 `T_Expense`（動態） |
| :--- | :--- | :--- |
| 新的那一列的小計 | 空白，要自己把 `=G12*H12` 複製下來 | **自動出現** `=[@單價]*[@數量]`（計算欄位） |
| 總計 | `=SUM(I2:I11)` **漏算**第 12 列，要回頭改成 `I2:I12` | `=SUM(T_Expense[小計金額])` **自動算進去** |
| 篩選按鈕、斑馬紋 | 要另外設定 | 表格自帶，也會跟著延伸 |
| 公式看得懂嗎 | `I2:I11` 是什麼？ | `小計金額`、`[@單價]` 一看就懂 |

- **`T_Expense[小計金額]`**：整個表格的「小計金額」欄，表格長大，範圍跟著長大。
- **`[@單價]`**：「這一列」的單價。寫在表格裡的公式用這種寫法，並設成**計算欄位**，新增列時 Excel 會自動帶出同樣的公式。

> 🔍 打開 xlsx 的「**固定範圍對照**」工作表，可以直接看到一般範圍漏算的樣子，不用自己動手試。

> 📌 **這一課也修正了舊版範例的三個問題**：日期改存成真日期；總計移到「報銷彙總」工作表，不貼在明細下面；SUM 範圍改成結構化參照，新增資料不會漏算。

## 5️⃣ 打開 xlsx 觀察

> ⬇️ **先下載檔案**：[部門費用報銷表.xlsx](https://github.com/roberthsu2003/ai-excel-analytics/raw/main/01_%E7%94%A8AI%E7%94%9F%E6%88%90Excel/04_%E4%B8%80%E5%88%97%E4%B8%80%E7%AD%86%E8%88%87%E7%B5%90%E6%A7%8B%E5%8C%96%E8%A1%A8%E6%A0%BC/%E9%83%A8%E9%96%80%E8%B2%BB%E7%94%A8%E5%A0%B1%E9%8A%B7%E8%A1%A8.xlsx)。下載後用 Excel 打開；在 GitHub 網頁上預覽看不到公式和格式。

### 工作表「報銷明細」
- [ ] 第 1 列表頭有篩選小箭頭。點「申請部門」的箭頭，看得到每個部門可以勾選。
- [ ] 點任一格資料，Excel 上方出現「**表格設計**」功能區，名稱是 `T_Expense`。
- [ ] 點 **B2**：靠右，是真日期。
- [ ] 點 **I2**：`=[@單價]*[@數量]`。這是表格的計算欄位，整欄都是同一個公式。
- [ ] 確認整張表**沒有標題列、沒有總計列**，第 1 列就是欄位名稱。

### 工作表「報銷彙總」
- [ ] 點 **B3**：`=SUM(T_Expense[小計金額])`，結果 **70,310**。
- [ ] 點 **B2**：筆數 **10**；**B4**：最大單筆 **25,000**（數位廣告）。

### 工作表「固定範圍對照」
- [ ] 同樣的報銷資料放在**一般範圍**，第 12 列（黃底）是新增的第 11 筆：計程車資 350 × 2 = 700。
- [ ] 點 **I2**：`=G2*H2`，一般範圍的寫法。
- [ ] 看 **N2**：`=SUM(I2:I11)` = **70,310**。這是 10 筆時寫的總計，範圍沒有跟著長大。
- [ ] 看 **N3**：實際應有 **71,010**；**N4** 漏算 **700**。

> 💡 回到「報銷明細」對照：如果同仁在第 12 列新增一筆，表格會自動往下延伸，小計自動帶出公式，「報銷彙總」的總計也自動算進去，**不用重寫任何公式**。
>
> 🧪 想親眼看看？可以在「報銷明細」第 12 列的 A12 輸入一個序號，再在 G12、H12 輸入單價和數量，I12 會自動算出小計。看完關閉檔案時不要存檔。

## 6️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 加大標題 | C1 寫「第 1 列為報表標題，合併 A1:K1」 | 「標題移除，第 1 列就是欄位名稱」 |
| 總計放在明細下面 | 「第 12 列為總計」 | 「總計移到彙總工作表」 |
| SUM 寫死範圍 | `=SUM(I2:I11)` | 「設成結構化表格，用 `T_Expense[小計金額]`」 |
| 表格裡的公式用一般位址 | 小計寫 `=G2*H2` | 「改成 `[@單價]*[@數量]`，並設成計算欄位」 |
| 同部門合併 | 「同部門儲存格合併美化」 | 「資料列不合併」 |
