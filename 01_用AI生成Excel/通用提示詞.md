# 💬 通用提示詞：四步流程，任何 AI 助理都適用

> 這套流程不限定哪一個 AI。只要你用的 AI 助理**能產生檔案**（可以讓你下載 `.xlsx`）就能用。
> 如果你的 AI 助理不能直接給檔案，第 ③ 步改請它「提供可執行的 Python 程式來產生 .xlsx」。

```mermaid
flowchart LR
    A["① 白話需求<br/>→ AI 寫規範書 .md"] --> B["② 你用檢查清單<br/>審規範書"]
    B -- 有問題 --> A
    B -- 全部打勾 --> C["③ 回覆「確認」<br/>→ AI 產生 .xlsx"]
    C --> D["④ 打開 .xlsx<br/>對照規範書觀察驗收"]
```

---

## ① 白話需求 → 請 AI 寫規範書

先附上 [規範書範本.md](./00_RTCCF規範書標準/規範書範本.md)（上傳檔案或貼上內容），再貼這段：

```text
我要請你幫我做一份 Excel 試算表，但請先不要產生 Excel 檔。

【我的需求（白話）】
（在這裡用自己的話描述：這張表做什麼用、誰填、誰看、要記錄哪些東西、要算什麼、有什麼要特別注意的）

【請你做的事】
1. 依照我附上的《RTCCF 試算表規範書標準》範本，把需求寫成一份 Markdown 規範書。
2. 五大段（Role、Task、Context、Constraints、Format）與 C1～C7 七小節都要有；用不到的小節寫「本課不適用」。
3. C2 欄位定義表每一欄都要寫：角色（標識／條件／指標）、資料型態、顯示格式、必填、說明。
4. 所有計算欄位都寫進 C3，使用 Excel 公式，不可填入算好的數字。
5. 只輸出規範書，等我回覆「確認」後才產生 Excel。
```

## ② 審規範書（你自己做）

拿 [規範書檢查清單.md](./00_RTCCF規範書標準/規範書檢查清單.md) 逐項打勾。有問題就請 AI 改，**一次指出一節**最清楚：

```text
請修改規範書：
- C2 的「報銷日期」資料型態請改成「日期」，顯示格式 yyyy-mm-dd。
- C1 請加上「總計不要放在明細最後一列下面，改放在另一張工作表」。
改完請輸出完整規範書，仍然先不要產生 Excel。
```

## ③ 確認 → 請 AI 產生 .xlsx

```text
規範書確認。請完全依照這份規範書產生 .xlsx 檔案：
1. C3 的計算欄位必須寫入 Excel 公式，不可寫入計算結果。
2. 日期欄存成真正的日期，金額欄存成數值。
3. 依 C4、C5 設定資料驗證與條件式格式。
4. 交付時附上驗收清單：哪些儲存格是公式、哪些有資料驗證、C7 的測試值在哪一列、應該看到什麼結果。
```

## ④ 打開 .xlsx 觀察驗收

| 檢查 | 怎麼看 | 對照規範書 |
| :--- | :--- | :--- |
| 公式是不是活的 | 點計算欄任一格，看資料編輯列是不是 `=` 開頭 | C3 |
| 型態對不對 | 日期、金額靠右；文字靠左 | C2 |
| 有沒有合併儲存格 | 點表頭的篩選按鈕能不能用 | C1 |
| 防呆有沒有作用 | 點有下拉選單的格子，看右邊有沒有小箭頭 | C4 |
| 警示有沒有作用 | C7 的測試值那一列有沒有變色 | C5、C7 |

發現問題時：

```text
驗收發現問題：（例如）I5 顯示 1160，但資料編輯列是數字不是公式。
請依規範書 C3 修正為 =G5*H5，並重新產生 .xlsx。
```
