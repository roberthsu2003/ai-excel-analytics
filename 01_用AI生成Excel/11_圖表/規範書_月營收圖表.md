# 試算表規範書：月營收圖表

> 依循：RTCCF 試算表規範書標準 v1｜版本：v1｜日期：2026-10-24

# Role
你是一位熟悉商業圖表與 Excel 圖表功能的資料分析師，依「問題類型」選擇圖表，並遵守圖表基本規則。

# Task
依 2025 年門市與線上的月營收，產生三張圖：趨勢用折線圖、比較用長條圖、組成用圓餅圖。圖表資料全部來自公式。
- 交付物：`月營收圖表.xlsx`，共 3 張工作表、3 張圖表

# Context
- 用途：年度營運簡報。
- 誰填寫：會計；誰閱讀：主管。
- 一列代表：月營收＝**一個月**；季彙總＝**一季**。
- 工作表清單：

| 工作表 | 角色 | 內容 |
| :--- | :--- | :--- |
| 月營收 | 資料層 | 結構化表格 `T_Revenue`，12 個月的門市、線上營收 |
| 季彙總 | 展示層（圖表資料） | 上方各季彙總（A1:E5）；下方全年通路營收（A8:B10），供圓餅圖使用 |
| 圖表 | 展示層 | 3 張圖表 |

# Constraints

## C1 結構規則
1. 資料列不合併儲存格。
2. 資料中間不留空白列、空白欄。
3. 一格只放一件事。
4. 第 1 列為欄位名稱，資料從第 2 列開始。
5. 凍結窗格：月營收 `A2`。
6. 結構化表格：月營收 `A1:D13`，名稱 `T_Revenue`；D 欄「合計營收」設為計算欄位。
7. **圖表的資料來源必須是儲存格範圍**（不可把數字寫死在圖表裡），資料改了圖表跟著變。
8. 圖表規則（呼應第二部）：數值軸從 0 開始、有圖表標題、有座標軸標題並註明單位。

## C2 欄位定義表

工作表：月營收

| 欄 | 欄位名稱 | 角色 | 資料型態 | 顯示格式 | 必填 | 說明 |
| :-: | :--- | :--- | :--- | :--- | :-: | :--- |
| A | 月份 | 條件 | 日期 | `yyyy-mm` | ✔ | 存成每月 1 日 |
| B | 門市營收 | 指標 | 數值（整數） | `#,##0` | ✔ | 元 |
| C | 線上營收 | 指標 | 數值（整數） | `#,##0` | ✔ | 元 |
| D | 合計營收 | 指標 | 公式 | `#,##0` | ✔ | 見 C3 |

工作表：季彙總

| 區塊 | 欄 | 內容 | 資料型態 | 顯示格式 |
| :--- | :--- | :--- | :--- | :--- |
| 各季 A1:E5 | A | 季別 Q1～Q4 | 文字 | 粗體 |
| | B | 起始月份（每季第一個月的 1 日） | 日期 | `yyyy-mm` |
| | C、D、E | 門市、線上、合計營收 | 公式 | `#,##0` |
| 全年 A8:B10 | A | 通路（門市、線上） | 文字 | 粗體 |
| | B | 全年營收 | 公式 | `#,##0` |

## C3 公式

| 儲存格 | 公式 | 白話說明 |
| :--- | :--- | :--- |
| 月營收!D 合計營收 | `=[@門市營收]+[@線上營收]`（計算欄位） | 門市 + 線上 |
| 季彙總!C2 | `=SUMIFS(T_Revenue[門市營收],T_Revenue[月份],">="&$B2,T_Revenue[月份],"<"&EDATE($B2,3))` | 月份落在「起始月份」起 3 個月內的加總；D 欄同理加總線上營收 |
| 季彙總!E2 | `=C2+D2` | |
| 季彙總!B9 | `=SUM(T_Revenue[門市營收])` | 門市全年 |
| 季彙總!B10 | `=SUM(T_Revenue[線上營收])` | 線上全年 |

> 不用 `=SUM('月營收'!B2:B4)` 這種寫死的範圍：月營收表格新增或重排月份時，SUMIFS 依日期加總，結果仍然正確。

## C7 示範資料
- 12 個月（2025-01 ～ 2025-12）。門市每月 76 萬～112 萬；線上從 29 萬逐月成長到 81 萬。
- 預期結果：門市全年 **10,830,000**、線上全年 **5,930,000**；四季合計 3,410,000、3,870,000、4,250,000、5,230,000。
- 觀察重點：折線圖應看出下半年明顯上升；圓餅圖約為門市 65%、線上 35%。
