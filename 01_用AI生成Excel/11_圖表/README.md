## 1️⃣ 白話需求

> 「年度簡報要三張圖：營收一整年怎麼變化、每季門市跟線上誰賣得多、全年門市跟線上各占多少。」

一句話裡藏了三種問題：**怎麼變化**（趨勢）、**誰多**（比較）、**各占多少**（組成）。

## 2️⃣ 問題 → 圖表

| 白話問題 | 問題類型 | 圖表 | 為什麼 |
| :--- | :--- | :--- | :--- |
| 一整年怎麼變化？ | 趨勢 | 折線圖 | 時間點多（12 個月），線條最能看出走勢 |
| 每季門市跟線上誰多？ | 比較 | 群組直條圖 | 項目少（4 季 × 2 通路），長條高度好比較 |
| 全年各占多少？ | 組成 | 圓餅圖 | 只有 2 類，切塊少，圓餅圖讀得懂 |

> 💡 這張表就是第二部第 4～6 課的內容。第一部的重點是：**把選圖結果寫進規範書 C6**，AI 就不會亂選。

## 4️⃣ 打開 xlsx 觀察

- [ ] 切到「圖表」：三張圖由上到下是折線、直條、圓餅。
- [ ] 看折線圖：Y 軸從 **0** 開始，有「營收（元）」軸標題；下半年明顯上升。
- [ ] 點一下折線圖，「月營收」工作表的 D 欄會被框起來，這就是**資料來源範圍**。
- [ ] 看直條圖：每季兩根，圖例標出門市、線上；Q4 最高。
- [ ] 看圓餅圖：只有 2 塊，標示百分比（門市約 65%）。
- [ ] 切到「季彙總」：點 **B2**，`=SUM('月營收'!B2:B4)`，圖表的數字也是公式算出來的。

## 5️⃣ AI 常見出錯點

| AI 可能寫錯 | 你在規範書看到的樣子 | 請 AI 改成 |
| :--- | :--- | :--- |
| 每張圖都用同一種 | C6 三張都是直條圖 | 「依問題類型：趨勢折線、比較長條、組成圓餅」 |
| 數值軸沒從 0 開始 | C6 沒寫 Y 軸起點 | 「數值軸從 0 開始」 |
| 圓餅切太多塊 | 用 12 個月做圓餅圖 | 「圓餅只用於 2～4 類的組成」 |
| 圖表是貼上的圖片 | 「插入 PNG 圖片」 | 「用 Excel 原生圖表，資料連到儲存格」 |
| 沒有軸標題與單位 | 只有圖表標題 | 「加 X、Y 軸標題，Y 軸註明元」 |
