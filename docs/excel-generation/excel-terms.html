🚨 4. 錯誤代碼：看到不要慌

驗收 AI 做的 xlsx 時，看到這些代碼就知道往哪裡找原因。

#VALUE!

型態不對：拿文字做數學，例如「180元」× 1。上面表格的 D4 就是。

#N/A

找不到：XLOOKUP 查不到這個編號（第 08 課）。

#REF!

參照不見了：公式指向的欄或工作表被刪除。

#DIV/0!

除以 0：分母是 0 或空白，要用 IF 防呆。

#NAME?

不認得名稱：函數打錯，或舊版 Excel 沒有 XLOOKUP、IFS。

#####

不是錯誤：欄太窄放不下，拉寬就好。
