🔑 貫穿全部的四條鐵律

1. 資料列不合併

一列就是一筆，才能排序、篩選、樞紐分析。

2. 型態要對

金額是數值（不打「元」），日期是日期，要保留 0 的編號存成文字。

3. 公式優先

算出來的都用公式，不填死值。

4. 資料和報表分開

明細放資料層，總計與圖表放展示層。
